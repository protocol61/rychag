# Рычаг — техника под ваши пропорции

Сайт: https://protocol61.github.io/rychag/ (3D: https://protocol61.github.io/rychag/3d.html)

2D-симулятор приседа, жима лёжа и становой тяги. Пользователь вводит рост,
вес, длины сегментов и подвижность и получает анимацию выгодной по физике
техники, моменты в суставах и сравнение вариантов (высокий/низкий гриф,
классика/сумо, жим ровно/с прогибом).

## Запуск

```sh
npm start        # python3 -m http.server 8000 → http://localhost:8000
npm test         # node --test, тесты физики
```

`3d.html` — 3D-вид (Three.js r186 из `node_modules`, нужен `npm install`).
Профиль общий с 2D-страницей.

Сборки нет: ES-модули в браузере. С `file://` модули не грузятся,
поэтому нужен любой статический сервер.

Инструкция по замерам открывается из панели «Замеры» или ссылкой
`#guide=body` / `#guide=mobility`. Высоты от пола пересчитываются в длины
сегментов (`js/measure.js`) и одной кнопкой подставляются в профиль.

Ссылка с параметрами: `#lift=bench&p=<base64 профиля>`, кнопка
«Скопировать ссылку». `#t=0.7` открывает анимацию на паузе в заданной фазе.

## Публикация

Пуш в `main` запускает `.github/workflows/pages.yml`: `npm ci` → `npm test` →
`npm run build` (собирает `_site/` вместе с нужными файлами three.js) →
деплой на GitHub Pages. Если тесты упали, сайт не обновляется.

## Структура

| Файл | Что делает |
|---|---|
| `js/anthropometry.js` | Пропорции (Drillis & Contini), массы и ЦМ сегментов (de Leva 1996), профиль по умолчанию |
| `js/solver.js` | Модели трёх упражнений и оптимизатор поз |
| `js/render.js` | Отрисовка сцены на canvas |
| `js/chart.js` | Графики моментов и углов |
| `js/app.js` | Форма, вкладки, анимация, выводы и сравнения |
| `js/rig3d.js` | 3D-скелет из кадра решателя: ширины, колени и локти через пересечение сфер (без three.js, тестируется в Node) |
| `js/scene3d.js` | Three.js-сцена: процедурный манекен, штанга, скамья; кадры запекаются в `AnimationClip` и играют через `AnimationMixer` (`LoopPingPong`) |
| `js/app3d.js` | Страница 3D: вкладки, ракурсы, проигрывание, текущие значения |
| `js/measure.js` | Инструкция по замерам: высоты от пола → длины, углы с телефона → подвижность |
| `test/solver.test.js` | Инварианты: баланс, длины звеньев, ограничения, плавность, чувствительность к пропорциям |

## Модель

Тело — цепочка жёстких звеньев в боковой проекции. Разворот стоп и колен
учитывается как поворот плоскости ног (горизонтальные компоненты × cos угла).

На каждом из 61 кадра решатель перебирает свободную степень свободы
(наклон голени; в жиме — положение грифа по горизонтали) и выбирает позу
лексикографически:

1. минимальное нарушение ограничений (с допуском 1,5);
2. минимум `J = Σ (M_j / C_j)²`, где `M_j` — статический момент в суставе,
   `C_j` — условная сила сустава (`CAPACITY` в `solver.js`).

Ограничения:

- **Присед**: общий ЦМ над серединой стопы (наклон торса подбирается
  бисекцией), предел голеностопа, угол бедро — торс, глубина ниже параллели.
- **Тяга**: гриф над серединой стопы, плечо над грифом, руки отвесно; гриф
  не проходит сквозь голень и бедро; угол бедро — торс.
- **Жим**: локоть — пересечение двух сфер (плечо и предплечье), ближайшее к
  заданному разведению локтей; касание между мечевидным отростком и
  сосковой линией; к локауту гриф над плечевым суставом; хват ≤ 81 см (IPF),
  автоподбор по минимуму пиковой нагрузки.

Отличие от MySquatMechanics: там углы задаются заранее придуманными
кривыми, а единственное ограничение — баланс. Здесь поза на каждом кадре —
результат оптимизации.

## Известные упрощения

- Статика: без инерции, скорости и ускорения грифа.
- `CAPACITY` — порядок величин, а не замер конкретного человека. От
  соотношения таз/колено зависит, куда оптимизатор «сдвигает» работу.
- В приседе при одинаковом положении ног моменты не зависят от положения
  грифа: это следствие баланса, а не ошибка. Разница high/low bar видна
  в наклоне торса и в требованиях к подвижности.
- Нет позвоночника как отдельной цепи: торс жёсткий, «угол бедро — торс»
  включает и таз, и поясницу.
- Ширина постановки в сумо не меняет высоту таза напрямую (только проекцию).
- Жим: высота груди — грубая оценка по росту плюс прогиб.
